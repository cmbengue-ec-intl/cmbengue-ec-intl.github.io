# Cheikh Mbengue’s website

Jekyll website published by GitHub Pages from `main`.

- Public entry point: https://cmbengue.org (redirects to GitHub Pages)
- Pages address: https://cmbengue-ec-intl.github.io/

## Local preview

Install the locked dependencies with `bundle install`, then run `bundle exec jekyll serve`. Open the local address printed by Jekyll. Run `bundle exec jekyll build` before proposing a release.

## Publishing

Use the issue–PR workflow in [CONTRIBUTING.md](CONTRIBUTING.md). Merging a release PR into `main` publishes the site through the existing GitHub Pages configuration. Verify the Pages build and the public site after merging. Do not change DNS or add a CNAME merely to refresh content.
